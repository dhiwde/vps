## 为什么搬瓦工在中文用户里长期被推荐

先说结论性的部分，但都是基于可核实的事实，不是替它喊口号。

搬瓦工的母公司是 IT7 Networks，自营硬件和 IP 段，不是转售别人机房的二道贩子。它的 VPS 基于 KVM 虚拟化，配套自研的 KiwiVM 控制面板，支持一键重装系统、快照、机房免费迁移、rDNS 设置、流量统计和 API 调用。对国内用户来说，几个实际有意义的点包括：

- **支付方式**：支持支付宝、银联、PayPal、信用卡，国内用户不需要折腾外币卡。
- **线路分级**：从普通 163 到 CN2 GT、再到 CN2 GIA / CTGNet，针对中国方向做了多档优化，这点对建站、远程办公、科学上网场景的用户特别关键。

- **退款政策**：30 天退款，对试错比较友好。

需要说清楚的是，搬瓦工是 **self-managed（自管理）** 服务，意思是它只提供 VPS 本身和网络，不替你装网站环境、不帮你查应用层问题。如果你完全不想碰命令行，需要的是带面板的托管型主机，那搬瓦工的定位其实不太合适——这点后面选购部分会再强调。

## 常见疑问

**搬瓦工稳不稳定？**
从官网公开信息看，它承诺 99.9% uptime SLA，并且节点每分钟检测一次。CN2 GIA 线路本身对中国方向稳定性较好，但要注意 CN2 GIA 容量有限，遇到 DDoS 时搬瓦工会做 IP nullrouting（直接黑洞），不像普通 163 线路那样能硬扛——这是 CN2 GIA 的固有特性，不是搬瓦工的问题。

**能换机房吗？**
标准 KVM 和 CN2 GIA-E 系列支持后台一键迁移机房，免费、不丢数据。香港 Ultra 系列因为是专属机房套餐，迁移选项有限，下单前最好确认好机房。

**续费价格会涨吗？**
使用循环折扣码下单的，续费时折扣依然有效，价格保持不变。如果用的是一次性折扣码，续费会回到原价。这也是为什么推荐 BWHCGLUKKB 这种 recurring 码。

**流量用超了怎么办？**
搬瓦工流量是按月计算，超出后会停机或限速（具体看套餐），不会自动扣费。可以在后台购买额外流量包或升级套餐。
